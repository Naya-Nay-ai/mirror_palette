# MIRROR_PALETTE

**Build the shape. Find the color.**

服のシルエットと正確な色を重ねて、コーディネートの組み合わせを試すカラーコーデアプリのMVP。
顔・髪のない無個性なマネキンを使い、服のかたちと色に集中できる画面です。

## 実装済み

- Top：クルーネックTシャツ／開襟ブラウス／ハイネックニット
- Bottom：Aラインスカート／ストレートパンツ／ワイドパンツ
- Shoes：パンプス／スニーカー／ショートブーツ
- 3カテゴリを独立して変更できるレイヤー式SVG表示
- HEX直接入力（6桁を即時反映、3桁はEnterまたはフォーカス移動で展開）
- ネイティブカラーピッカーと12色のプリセット
- サンプルコーデの初期表示とリセット
- コーデに名前を付けて複数保存、サムネイルとスウォッチ表示、呼び出し、削除
- localStorageのバージョン管理・形式検証・保存失敗の表示
- PC／タブレット／モバイル対応、キーボード操作、減らす設定に対応したモーション
- 日本語UI、同梱フォント（Google Fontsへのブラウザ通信不要）

服の基本塗りは入力されたsRGB HEXの単色です。グラデーション、半透明、フィルターで服の基本色を変化させません。縫い目は細い線、スニーカーの靴底は固定の白系色で表現しています。画面上の色はディスプレイの設定に影響され、実物の生地や照明を再現するものではありません。

## 起動

Node.js 20.9以降（Node.js 22以降推奨）。

```bash
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

```bash
npm run typecheck
npm run build
npm start
```

`build` はローカルでのビルド検証であり、公開先へのデプロイは行いません。

## 保存について

- キー：`mirror-palette:saved-looks:v1`
- 形式：`{ version: 1, looks: [{ id, name, savedAt, look: { top, bottom, shoes } }] }`
- 各アイテム：`{ shape, color }`
- 保存先はそのブラウザとサイトの組み合わせです。別の端末・ブラウザ・別ドメインのPreview URLには自動同期されません。
- ブラウザのサイトデータを消去するとコーデも消えます。
- 保存前の編集状態はページ再読込でサンプルに戻ります。保存済みコーデは一覧から呼び出せます。
- 壊れた保存データを読み込んでも自動では書き換えません。明示的な保存操作時に新しい内容を書き込みます。

## Preview確認

Vercel Project：`mirror-palette`、Team：`Mirror Room`。

1. Preview URLを開きます。保護されている場合は所有者のVercelアカウントでログインしてください。
2. Top／Bottom／Shoesを切り替え、シルエットを選びます。
3. HEX、カラーピッカー、プリセットで色を変更します。
4. 名前を付けて保存します。
5. 再読込後、Saved looksから開き、3アイテムの種類と色が復元されることを確認します。

ソースの作業ブランチは `preview/mvp`。この成果には環境変数やAPIキーは不要です。
